# Co-Thinker · 对话与思考页

2026-09-19，研究后的第二版实现候选。用户已授权“再去研究，之后去制作”；随后质疑本版的审美及时代参照。本文件保留实现时的设计假设，不代表方向已被认可或效果已得到验证。

## 同一件事如何贯穿设计

人可以先把想法说出来。一段值得继续琢磨的话，可以从对话中留到手边，保持出处，也允许改写。引用它继续讨论时，材料与自己的新表达一并进入模型；后台继续维护共同记录。这个过程决定空间、文字层级、交互和状态，而不是给各领域分别添加组件。

桌面宽屏使用一张安静的思考页承接当前问题、手边摘录与后台记录。它与对话并置，便于比较；可以收起。窄屏改为按需打开，保留对话阅读宽度。会话历史作为导航抽屉，不常驻成为第三个阅读对象。

手边内容是讨论材料，不等于确认共识；不自动成为系统约束。只有通过“聊这一点”明确引用时进入下一轮。改写保留原文及出处，不更改历史消息。会话之间、预览与正式模式之间的摘录分别存储；数据只保存在本机浏览器，不能冒充跨设备同步。

## 视觉与节奏

- 浅石色背景，深墨色文字，墨绿色用于少量交互强调。正文使用适合中文屏幕阅读的系统字体；品牌采用系统衬线字作为次要的识别特征。无外部字体下载依赖。
- 内容以标题、行距、疏密与文字重量组织。思考页中的试探材料与既有记录有明确身份，不靠成排同质卡片组织所有信息。
- 输入接收、生成和记忆整理显示各自的真实状态；不展示模型自评分，不用装饰性颜色假装“更懂了”。
- 动效用于新内容到达、摘录出现和视线定位；不延迟真实模型输出。保留打断、回改、滚动阅读与 reduced motion。

## 参考及取舍

- [Muse 原设计记录](https://www.inkandswitch.com/muse/)：阅读了 shelf、excerpting、text 等相关设计说明。借鉴内容可被取出、留在手边并回到来源的关系；不复制触控无限画布。
- [iA Writer 响应式文字设计](https://ia.net/topics/bringing-responsiveness-the-app-world)：阅读原团队完整短文。借鉴排版与使用情境共同决定；不复制其早期固定字号、强制 Focus Mode。
- [Apple Typography](https://developer.apple.com/design/human-interface-guidelines/typography)：层级与尺寸、重量、阅读条件一起处理，不以细字或低对比代表精致。
- [Geist 的 Anthropic 案例](https://geist.co/work/anthropic)：选择应形成完整气质；不复制其专有字体与品牌样式。

以上是设计实践的输入，不构成本项目效果证据。详细的哲学、美学和认知研究保存在当前工作区的 co-thinker-audit 目录。

## 实现与验收

在已有 Workbench 组件内重新组织视觉与交互，新增独立 token、手边材料组件与会话存储逻辑；保留旧界面代码、后端端点与会话数据。实现后检查真实内容的阅读、摘录、改写、定位、引用、切换会话、异步记录、打断和导出。宽窄屏、键盘、中文 IME、浅深外观均纳入检查。

当前本机没有已配置模型 Key。预览明确使用预设回复，只验证交互和状态；不能用预览证明模型启发性、理解准确率或真实心流。
