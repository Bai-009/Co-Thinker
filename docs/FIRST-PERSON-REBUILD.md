## 重构的对象

页面以持续的思考活动为中心。对话和地基是同一内容的两种观察方式，输入框始终保留。地基直接呈现第一人称的叙述，保留未决定之处；条目与变化需要时再展开。不将来自人的表达与模型提议做成两组面向用户的成果。

前台的消息顺序仍可辨认，协议角色继续用于模型与存储。引用作为讨论对象传入后续表达，未被当成认可。Brief 是阶段性交接的出口，不强迫每轮交流走向需求文档。

新组件、字号系统、颜色和阅读布局独立实现，不导入旧版页面组件或 CSS。正文相近的字号与字色避免把输入降为注释；地基作为主要阅读内容呈现。具体布局、字号和文案尚未被用户认可。

## 可以实际操作的路径

1. 对话中继续输入，或从预览页脚载入一条示例。
2. 在生成过程中切换到地基，旧理解仍可读，后台更新完成后替换；不要求手动整理。
3. 从地基引用一段继续说，草稿与引用均保留。发送后回到当前对话，引用和新表达分别编码。
4. 修改最近一次输入，走真实 edit 路径；前端与异步状态回退。停止后可以继续，空回复中止后刷新也有接续入口。
5. 需要交接时生成 Brief，复制或下载 Markdown。预览的导出保留示例标记。
6. 示例结束后“重看示例”创建新的本地示例会话，不删除已有记录。真实会话与示例存储隔离。
