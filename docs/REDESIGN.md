# Co-Thinker 改造候选 · 2026-09-19

分支：`codex/co-thinker-redesign`。当前是可操作的本机候选，尚未获得用户对视觉方向的认可；没有推送或合并。

## 产品判断与界面分工

产品中心是共同思考的过程。人带来经验、意图和修订，模型带来知识、关联和判断。Brief 是可选出口。短回复只是保持参与机会的一种方式，不能替代有价值的回应。

默认页面只呈现当前对话与输入。左侧历史、右侧共同记录均按需展开。记录继续后台更新，不因面板收起而停止；导出入口留在记录里。消息操作在指向或键盘聚焦时出现，触屏直接可见。选中具体文字可带着引用继续交流，记录也可作为引用进入下一轮。

这次没有保留整页置信度变色：模型自评分不能可靠解释究竟哪里需要重新判断。先提供可操作、能指向具体话语的反馈。后续可讨论更细的非语言反馈，不把装饰动画当作模型注意力。

## 跨领域依据与取舍

| 视角 | 对本项目的影响 | 本轮落点 |
| --- | --- | --- |
| 美学与信息层级 | 阅读对象优先于控件，留白服务于连续阅读 | 单一对话主区、可读行长、浅深主题、按需记录 |
| 人类认知 | 要求边表达边管理结论，会争夺注意力 | 前台不等待记忆整理；不强制逐条批准所有记录 |
| 共同思考 | 新观点、异议与改口都需要留有位置 | 引用续聊、打断、回改、可修订记录 |
| LLM 行为 | 短文本不等于有判断；持续追问也会消耗用户 | Prompt 不再默认“新话题先问”，按实际缺口选择回应 |
| Agent 状态 | 异步速度差、取消、旧任务写回会破坏共同理解 | 固定轮次快照、版本失效、分离前台和记忆锁 |
| 产品实现 | 模拟只能验证操作，不能证明思考质量 | 明确的预览模式与正式模型模式；分开标注验证范围 |

参考（设计输入，不是本产品效果证据）：
- [Apple — Design foundations from idea to interface](https://developer.apple.com/videos/play/wwdc2025/359/)：信息架构、渐进披露和视觉层级应一起决定界面。
- [Horvitz — Principles of Mixed-Initiative User Interfaces](https://www.microsoft.com/en-us/research/publication/principles-mixed-initiative-user-interfaces/)：自动化介入时机、用户注意力以及纠正机会需要同时考虑。
- [Anthropic — Disempowerment patterns in real-world AI usage](https://www.anthropic.com/research/disempowerment-patterns)：将判断转交模型存在风险；不能把顺从和确信的语气当作良好协作的证据。

这些依据用于建立可检验的设计选择，不证明当前版本已经产生心流、提高创造力或消除迎合。

## 已实现

- 统一的 IM 对话界面，桌面/窄屏、浅色/深色、中文输入法 Enter 保护、自动增高输入框。
- 明确的生成与结束状态；可打断、继续输入、回改上一条。阅读旧内容时不自动拖回底部。
- 引用某段回答、选中文字或共同记录续聊；引用随输入进入下一轮上下文。
- 共同记录按需展开，显示实际后台状态、已形成的判断、待讨论内容与已有计划；Markdown 删除线可表现修订。
- Brief 流式生成、复制、下载；生成使用同一份会话快照，并携带计划和未确认状态。
- 失败保留用户输入，重试替换失败轮而不重复追加。
- 每个后台记忆任务固定消息快照与版本，回改/重置使旧任务失效，快照归属原轮次；显式空块可清除旧冲突。
- Judge 改为可选后台评价（`COTHINKER_JUDGE=1`），不阻塞记忆队列，当前 UI 不以分数呈现“正确率”。

旧界面入口代码保留为 `frontend/src/LegacyApp.jsx`，旧组件与 `index.css` 保留，基准提交为 `30dbdeb`。没有更改项目远端可见性。

## 本机预览

- `http://127.0.0.1:8793/?preview=1`：预设回复的交互预览，不调用模型。示例数据与正式会话分开存储。
- `http://127.0.0.1:8793/`：真实后端模式；模型 Key、地址和名称沿用仓库 `.env.example` 的配置。密钥不进入前端。
- 预览模式的“示例接话”可以体验下一轮、记录更新、回改与 Brief。自由输入不伪装成真实模型回答。

构建前端后，FastAPI 会同时提供静态页面。标准运行方式：

```sh
cd frontend
npm ci
npm run build
cd ../backend
python -m uvicorn main:app --host 127.0.0.1 --port 8793
```

需先按原项目要求安装 Python 依赖。设置 `COTHINKER_DB` 为本机 SQLite 路径可持久化会话。本次预览使用仓库外审阅目录中的独立数据库。

## 验证与边界

- 后端 59 项测试通过，覆盖轮次错配、回改使旧任务失效、空记忆清除、模型异常保留输入、重试去重、取消、重置后的旧回复防写回。
- 前端 32 项测试通过，包含中文 IME、截断回复解析、会话 ID 迟到响应、切换会话的结果隔离；生产构建通过。
- 浏览器实际操作：示例续聊、停止、回改入口、共同记录引用、Brief 生成、窄屏记录抽屉、正式模式失败与重试、刷新后输入仍存在。
- 窄屏实际 CSS 宽度 320px 时无横向溢出，输入区仍有可用宽度。
- 本机未配置模型 Key；没有调用真实模型来验证新 Prompt 的创造性、判断力或长期记忆质量。下一次必须用真实对话验证，不能以预设样例代替。
- 当前是单进程本机架构；未改造成多用户服务。长会话的 context 预算/压缩、语义共识准入准确率和记忆版本 UI 的深化仍待后续工作。
