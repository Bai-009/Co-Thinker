# Co-Thinker 前端候选：连续讨论与相关材料

2026-09-20。依据用户提供的《前端重构叙事规格》实施，具体视觉与布局尚待用户评价。此次授权恢复前端制作；旧版本及原规格保留。

## 查看

在 `frontend` 执行 `npm run dev -- --host 127.0.0.1 --port 8795`，打开 `http://127.0.0.1:8795/inquiry.html?preview=1`。当前交付使用本地预设回复，页面与说明均标注这一边界。移除 preview 参数时复用原会话 API；本轮未配置或评测真实模型。

默认从“灵感与记录”的讨论进入。输入区下方“载入下一句”只填草稿，需要发送后才推进。左上角记录入口可新建另一段书店讨论。任何其他输入会被保留，但不会伪装成真实模型回复。

## 本轮的设计取舍

主要阅读区保留连续讨论，表达与回应使用相同正文尺度，以底色和段距辨认可回改输入。无贡献排行、角色头像、全页置信度染色和宣传文案。中文正文 16px，标题承担定位，不把地基放大为展示标题。

宽屏相邻区域呈现少量比较材料及地基入口；窄屏以原生对话框打开，关闭后继续原讨论。材料保留“正在推敲”状态，引用只是把特定内容带入输入框。地基使用第一人称并保留未决关系，后台更新状态保持次要位置。

原文定位、局部引用、输入补充、停止、最近输入回改、地基回看和 Brief 沿同一套文字、颜色与控件关系展开。读取历史时不因新 token 强行回到底部；打开材料不清除草稿。取消回改恢复原来尚未发送的内容。不同会话的草稿在本次页面生命周期内分别保留。

## 实现边界

- 新入口 `frontend/inquiry.html`，组件与样式位于 `frontend/src/inquiry/`。构建配置及预览传输增加入口路由，旧页面、后台与 Prompt 本轮未改。
- 正式控制复用 `src/core/useThoughtSession.js`，未另造视觉停止按钮。示例传输具有独立存储、流式输出、取消、后台延迟更新及版本检查。
- 引用记录会话、消息位置、来源内容版本与选择偏移；引用与新增表达分开编码。相同文字出现在另一条消息时不会通过模糊匹配改指向；源内容变化后拒绝定位。消息被改写后不声称建立了任意历史分支。
- 这仍是前端候选。比较材料及地基历史在示例数据中有明确结构；现有真实接口没有返回相应字段时，界面不会凭关键词制造比较卡片。完整模型侧材料生成契约仍需另行设计。
- 示例 Brief 冻结请求时内容，尚未沉淀的输入另列“新增表达，尚待核对”；这不等同于真实后端已完成语义综合与导出版本协议。本轮未调整其原有实现。
- 后台地基写入正确、文案示例成立和真实模型思考质量属于不同验证对象。此版本仅提供前两类的局部验证证据。
