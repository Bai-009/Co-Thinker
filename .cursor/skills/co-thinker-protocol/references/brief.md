# Brief — 执行简报蒸馏

把整次思考活动凝结成给**没参与过这次思考**的执行 agent 的心智简报。

## 位置

- 简报不是 prompt 模板，是交接物
- 简报里的「我」= 人那一边的托付视角（输出物体裁，不违反 principles）
- 目标：执行方看到后知道**怎么做**，而不是还要再问一遍「到底要什么」

## 结构（必须按此七段）

```markdown
## 我想做什么
## 背景和动机
## 关键判断
## 不要做什么
## 风格和审美锚点
## 执行约束
## 给执行 Agent 的话
```

## 写作要求

- 第一人称「我」
- 短段落（每段 1–3 句）
- 对话里已有的具体决定要写明；不要为了简洁含混回去
- 某段没有信息 → 写「（暂无明确判断）」，禁止编造
- 凝结，不是对话摘录
- 若 foundation 里有 plan，把未完成项反映进「我想做什么 / 给执行 Agent 的话」，但不要把简报写成 checkbox 清单的复读

## 输出

写入 `.cothinker/<slug>/brief.md`，从 `## 我想做什么` 起篇。
不要包在代码围栏或前置说明里。
