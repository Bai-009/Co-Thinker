这是按顺序推进的预设场景，文本框识别有限的示例意图；未覆盖或顺序不符时明确提示，不假装调用模型。相关表达保留用户实际输入。场景的时间间隔仅用于原型呈现，不是未来模型运行节奏的规定。数据只在当前页面存活；刷新或重新体验从头开始。
