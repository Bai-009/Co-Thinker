# Co-Thinker · 体验原型 v5

入口：http://127.0.0.1:8794/studio/ 。2026-09-19，延续第四版的原型路由；真实应用、后台及 v3 不变。当前设计待用户评价。

本轮从完整交流重新组织原型：AI 带来长椅的联想，用户补入共同兴趣；两人通过座位草图推敲人与人的距离，反例促使 AI 撤回“以促成交谈为目标”的前提；AI 随后反对全部使用长桌，提出让独立座位与共用桌面并存。讨论允许暂时停住，不强制生成完整方案。

## 操作

点击输入框下方“填入示例”，阅读后发送。共五轮后续交流。示例不是可自由输入的模型；仅接受对应的完整预设回复（空格和标点差异不影响识别）。不支持的输入保留，不替用户编造回应。

- 草图在对话中出现，对坐、错开、并坐可切换；比较操作不作为用户确认，也不写入讨论笔记。
- 顶栏“草图”和相关消息内入口可回到共同材料；后续提议在同一草图中加入单人位。
- 笔记在回复后异步更新；用户表达、AI 提议、未决问题分开保存，修订依据可追溯到原话。
- 停止后可继续回复。页脚左箭头回退上一轮，同时回退对话、草图和笔记；过期异步写入失效。
- 复制笔记使用浏览器剪贴板；不可用时在面板内展开并选中原文，可手动复制。
- 刷新或重新演示清空本次状态，不写入真实记忆。

## 形式与取舍

围绕一条连续阅读线重新调整字形、行长、留白、字标和输入区。主题标题采用本机宋体族，正文使用本机无衬线字体，不增加外部字体依赖。字体搭配是视觉候选，不以宋体代替所追求的学养。

不再从选择题开始。段落提供具体联系和分歧；草图作为共同讨论的对象出现，未成为固定第二栏。完整记录仍按需打开。去掉每轮正式确认卡片；确认与来源关系保留在笔记中。

消息到达时定位回应开头，保留先前段落，不因后续草图的高度将开头卷走。正在浏览历史时不强制回到底部。减少动画偏好下禁用持续动画与平滑滚动。
